1. Event Handling Programming

Understanding Java's Delegation Event Model, Event Classes, and Listener Interfaces

What is Event Handling?

Event handling is the mechanism through which a Java program responds to user actions, such as clicking a button, pressing a key, moving the mouse, or closing a window.

  • An event is an action performed by the user or system.
  • An event source generates the event.
  • An event listener detects the event and executes the corresponding code.

Example: Clicking a button generates an event, which triggers a specific action.

Java's Delegation Event Model

Java uses the Delegation Event Model to handle events. The responsibility of handling an event is delegated from the event source to a registered listener.

Three Main Components:

  1. Event Source: The component that generates an event (e.g., JButton).
  2. Event Object: Contains information about the event (e.g., ActionEvent).
  3. Event Listener: An object that receives and handles the event.

Event Classes

Event classes represent different types of events that occur in a GUI. They contain information about the event and are generally present in the java.awt.event package.

Event Class Purpose & Trigger
ActionEvent Button clicks, menu selections
MouseEvent Mouse clicks, movement, drag, enter/exit
KeyEvent Keyboard actions (key press, release, typing)
WindowEvent Window opening, closing, activating, iconifying
ItemEvent Checkbox or choice selection changes
FocusEvent Component gaining or losing focus

Listener Interfaces

Listener interfaces define methods that must be implemented to handle specific events. They are used to receive notifications from event sources.

Listener Interface Purpose Primary Methods
ActionListener Handles action events actionPerformed(ActionEvent e)
MouseListener Handles mouse clicks and other mouse actions mouseClicked(), mousePressed(), mouseReleased(), mouseEntered(), mouseExited()
KeyListener Handles keyboard events keyPressed(), keyReleased(), keyTyped()
WindowListener Handles window events windowOpened(), windowClosing(), windowClosed(), windowActivated()
ItemListener Handles item selection changes itemStateChanged(ItemEvent e)
FocusListener Handles focus changes focusGained(FocusEvent e), focusLost(FocusEvent e)

Java Implementation Example

Here, ActionListener listens for button clicks and executes the code when the event occurs:

// Registering an ActionListener on a JButton using a lambda
button.addActionListener(e -> {
    System.out.println("Button clicked!");
});

2. GUI Programming

Creating user-friendly graphical applications in Java

What is GUI Programming?

GUI (Graphical User Interface) programming involves creating applications that allow users to interact through graphical elements instead of command-line instructions.

Instead of typing commands in a terminal, users interact visually with windows, buttons, text fields, checkboxes, and menus.

Common GUI Elements Include:

Buttons Text fields Labels Checkboxes Menus Windows

Java's Two Major GUI Toolkits

Java provides two major GUI toolkits for developers:

1. AWT (Abstract Window Toolkit)

  • Java's original GUI framework.
  • Package: java.awt
  • Heavyweight components (relies on native operating system widgets).
  • Platform-dependent appearance.

2. Swing

  • Advanced GUI toolkit built on top of AWT.
  • Package: javax.swing
  • Lightweight components (drawn by Java itself).
  • Platform-independent appearance & pluggable Look and Feel.

4. AWT Hierarchy of Classes

Exploring the object-oriented inheritance tree behind Java's GUI architecture

AWT (Abstract Window Toolkit) Hierarchy

AWT is Java's original GUI framework. It provides classes for creating windows, buttons, text fields, and other graphical components.

Its class hierarchy is broadly divided into two main branches extending from Object: Component and MenuComponent.

  • Component: Base class for visible GUI elements.
  • Container: A component that can hold other components.
  • Frame: A top-level window with a title bar and borders.
  • Panel: A container used to group components.

5. Introduction to Swing Package

Java's advanced, platform-independent GUI toolkit built on top of AWT

What is Swing?

Swing is an advanced Java GUI toolkit built on top of AWT. It belongs to the javax.swing package and provides more flexible and feature-rich components.

Core Features:

  • Platform-independent appearance: Displays identically across Windows, macOS, Linux.
  • Lightweight components: Mostly drawn by Java rather than relying on native OS widgets.
  • Pluggable Look and Feel: Allows dynamically switching interface themes (Metal, Nimbus, Windows, System).
  • Supports advanced components: Includes tables, trees, tabbed panes, and scroll panes.

AWT vs Swing Component Comparison

Swing provides equivalent lightweight components prefixed with the letter J:

AWT Component (Heavyweight) Swing Component (Lightweight) Description
Button JButton Push button with text, icon, and action listeners
Label JLabel Text or image display label
TextField JTextField Single-line user text input
TextArea JTextArea Multi-line plain text editing area
Checkbox JCheckBox Toggable option box with state listener
Frame JFrame Top-level window with title bar and borders
Panel JPanel Container used to group components inside a window

6. Frames, Panels, and Layout Managers

Windows, containers, and automatic layout positioning in Java GUI

Frames

A Frame is a top-level window that acts as the main container of a GUI application. In Swing, JFrame is used to create a window.

Important Methods:

  • setSize(width, height) – Sets window dimensions.
  • setTitle(String title) – Sets window title.
  • setVisible(boolean b) – Displays or hides the window.
  • setDefaultCloseOperation(int op) – Defines what happens when the window closes (e.g., JFrame.EXIT_ON_CLOSE).
import javax.swing.*;

class MyWindow {
    public static void main(String[] args) {
        JFrame frame = new JFrame("My Application");
        frame.setSize(400, 300);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setVisible(true);
    }
}

Panels

A Panel is a container used to group and organize multiple GUI components inside a window. In Swing, JPanel is used.

JPanel panel = new JPanel();
panel.add(new JButton("Submit"));
panel.add(new JLabel("Enter Name:"));

frame.add(panel);
Key difference: JFrame represents the main window, whereas JPanel groups components inside that window.

Layout Managers

Layout managers automatically control the size and positioning of components inside a container. They make GUI designs flexible and adaptable to window resizing.

Layout Manager Arrangement Behavior
1. FlowLayout Arranges components sequentially from left to right. Moves components to the next row when space is insufficient.
2. BorderLayout Divides the container into five regions: North, South, East, West, and Center.
3. GridLayout Arranges components in a rectangular grid of rows and columns, with equal-sized cells.
4. CardLayout Arranges components like a stack of cards, displaying only one card at a time.
5. GridBagLayout Arranges components in a flexible grid where components can occupy different sizes and multiple cells.
